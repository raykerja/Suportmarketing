# Template workflow n8n

File `*.template.json` adalah salinan portabel dari alur riset target, surat teks ke Drive, kunjungan ke Sheet, dan **draft generator penawaran website**. Seluruh **credential binding**, `webhookId`, dan nilai `X-RAY-Secret` asli telah dihapus/diganti placeholder. ID spreadsheet pada template kunjungan juga diganti `SET_SPREADSHEET_ID`.

`offer-documents.template.json` adalah workflow **baru dan belum aktif**. Webhook `raykerja-offer` menerima data dari Edge Function setelah target disetujui dan UMK diisi. Workflow menyalin template RAB dan Google Docs, mengisi sel `A4`, `B10`, `G10`, `J36` pada RAB serta placeholder surat, memindahkan kedua salinan ke folder Drive akun, lalu callback ke Supabase. Ganti `SET_RAB_TEMPLATE_ID` dengan ID draf RAB yang telah dinilai, `SET_DOC_TEMPLATE_ID` dengan ID template surat, `SET_COUNTER_SHEET_ID` dengan ID counter nomor surat, dan `SET_MARKETING_WEBHOOK_SECRET` dengan secret yang sama pada Edge Function. Pilih ulang credential Google Sheets, Google Drive, Google Docs, dan HTTP Request Google Sheets; periksa setiap node sebelum aktivasi.

Workflow Telegram `RAY - Generator Dokumen Penawaran` tetap independen. Keduanya memakai counter nomor surat yang sama; bila dua permintaan dijalankan hampir bersamaan, nomor dapat berbenturan karena Sheet tidak menyediakan increment atomik pada pola ini. Periksa nomor surat saat uji produksi dan pertimbangkan satu layanan penomoran transaksi untuk semua kanal sebelum volume meningkat. Bila counter tahun berjalan belum memiliki baris, workflow web berhenti sebelum menyalin dokumen; tambahkan baris tahun sesuai prosedur administrasi penomoran sebelum pergantian tahun.

Untuk lingkungan baru: impor template sebagai workflow **nonaktif**, pilih ulang credential OpenAI/Google Search/Google Drive/Google Sheets pada node yang memerlukannya, isi ID Sheet dan secret webhook yang sama dengan Edge Function, periksa semua URL callback dan path webhook, lalu uji end-to-end sebelum aktivasi. Jangan aktifkan template mentah; placeholder belum terkonfigurasi.

Workflow production saat ini sudah aktif dengan ID pada `PROJECT_HANDOFF.md`. Template ini merupakan bahan pemulihan/migrasi, bukan backup credential atau export execution history. Script `scripts/export_portable_workflows.py` dapat membuat ulang template dari draft privat bila draft tersebut tersedia secara lokal.

## Revisi pencarian RUP pemerintah (draft 2026-10-04)

`target-research.template.json` kini berisi rancangan pengganti tool `sirup_search` yang memakai credential Serper yang sudah digunakan `google_search` untuk menemukan **ekspor RUP/SiRUP resmi** pada domain instansi `go.id`. Endpoint langsung SiRUP pada workflow aktif mengunci `tahunAnggaran=2026` dan pada pemeriksaan GET mengembalikan HTTP 200 dengan isi kosong. Template ini tidak mengklaim akses API SiRUP real-time. Pada saat memasang revisi ke workflow aktif, ganti hanya parameter tool dan prompt/parser/penyusun hasil yang berubah, lalu pasang credential Serper yang sama. Pertahankan webhook, node Drive, callback, dan node lain.

Untuk riset tahun 2026, cari **TA 2025** sebagai pembanding. Tahun pemilihan pada baris RUP dapat berbeda dari tahun anggaran. Pagu adalah rencana tahun lalu; jumlah personel perlu bukti eksplisit di paket/KAK/RKS. Jika dokumen tidak ditemukan atau tidak menuliskan jumlah, tampilkan `Belum ditemukan`/`Belum terverifikasi`, jangan menghitung personel dari pagu. Uji dengan satu dokumen RUP pemerintah yang dapat dibuka, lalu cocokkan nilai pada dokumen asli sebelum mengaktifkan perubahan production.
